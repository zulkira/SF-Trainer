Playbook

Ryu fundamentals

Weekly rhythm

Aim for repeatable quality, not endless volume.

  • Session A — Ranked: 2–3 focused blocks; stop when decision quality drops.
  • Session B — Replay: review 2 losses and 1 win; write one actionable cue.
  • Session C — Long set: play FT10/FT15; track opponent habits and late-set composure.
  • Optional — Fundamentals: anti-air consistency, whiff punishes, confirms and spacing.

Replay review steps

  1. Find the turning point, not every mistake.
  2. Separate execution error from decision error.
  3. Use Replay Takeover to test one alternative.
  4. Write the cue in plain language.
  5. Check the cue in the next session.

Long-set rules

  1. First few games: observe habits; avoid forcing a premature adaptation.
  2. When a pattern is confirmed, test one counter-option.
  3. If the opponent adapts, don't autopilot the same answer.
  4. After a bad loss, take one breath before queueing the next game.
  5. Review the process after the set, not during every interaction.
